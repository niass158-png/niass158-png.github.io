A&A Group — l'application de l'équipe, sur votre téléphone

Android recommandé

  1. Ouvrez cette page dans Chrome.
  2. Touchez Ouvrir le registre ci-dessous, puis le menu ⋮ → Installer l'application (ou « Ajouter à l'écran d'accueil »).
  3. L'icône A&A apparaît avec vos applications ; le registre s'ouvre en plein écran.

iPhone et iPad

  1. Ouvrez cette page dans Safari (pas dans un autre navigateur).
  2. Touchez Ouvrir le registre, puis le bouton Partager (le carré avec une flèche vers le haut).
  3. Choisissez Sur l'écran d'accueil, puis Ajouter.
Ouvrir le registre

Apple ne permet pas d'installer une application hors de l'App Store sans compte développeur : l'écran d'accueil donne le même résultat — icône, plein écran, mises à jour automatiques.

Première ouverture

  1. Saisissez votre prénom et nom, puis le code d'équipe communiqué par l'administrateur.
  2. Le code n'est pas conservé : l'appareil garde seulement la session ouverte, jusqu'à « Se déconnecter » (Paramètres).
  3. La veille automatique, les fenêtres de consultation et Tender AI restent sur le logiciel installé sur PC ; le téléphone voit tout ce qu'ils ajoutent.
